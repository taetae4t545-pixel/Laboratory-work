# Практическая работа № 2 — эмпирическое измерение сложности

## Назначение модуля
Модуль `lab01` предоставляет три функции:
- `linear_search` — линейный поиск индекса элемента;
- `binary_search` — бинарный поиск в отсортированном массиве;
- `count_pairs_sum` — подсчёт числа пар с заданной суммой (наивный двойной цикл).

## Гарантии по сложности

| Операция           | Время      | Память |
|--------------------|------------|--------|
| `linear_search`    | O(n)       | O(1)   |
| `binary_search`    | O(log n)   | O(1)   |
| `count_pairs_sum`  | O(n²)      | O(1)   |

## Ограничения на входные данные
- `binary_search` требует **отсортированный по возрастанию** вектор.
- `count_pairs_sum` — наивная реализация, применима только при небольших n.
- Функции возвращают `-1`, если элемент не найден.

## Известные ограничения
- `count_pairs_sum` — O(n²) по времени; для больших n непригодна.
- `binary_search` не проверяет факт сортировки.
